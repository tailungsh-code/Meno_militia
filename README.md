# Neon Militia

لعبة أكشن وإطلاق نار ثنائية الأبعاد (2D Platformer Shooter) بأسلوب نيون داكن، مستوحاة من Mini Militia.
ملف واحد فقط (`index.html`) يحتوي HTML + CSS + JavaScript، بدون صور أو أصوات خارجية (الرسم عبر Canvas والصوت عبر Web Audio API).

## التشغيل على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub وارفع الملفين `index.html` و `README.md` إلى الجذر.
2. من **Settings → Pages** اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط الناتج `https://<username>.github.io/<repo>/` على الهاتف.

> يمكن أيضاً فتح `index.html` مباشرة في المتصفح لتجربة اللعب الفردي.

## أوضاع اللعب
- **لعب فردي**: ضد بوت (يتحرك، يتفادى الحواجز، يطير، ويصوّب عليك).
- **لعب جماعي (PeerJS)**: لاعب يضغط «إنشاء غرفة» فيظهر كود من 4 أرقام، والآخر يدخله في «انضمام لغرفة».
  - يستخدم اتصال WebRTC مباشراً بين الجهازين، ويُفضّل أن يكونا على نفس الواي فاي أو الـ Hotspot.
  - مكتبة PeerJS تُحمَّل من CDN وتستخدم خادم الإشارة المجاني الافتراضي، لذلك يحتاج بدء الاتصال إلى إنترنت.
  - المضيف (منشئ الغرفة) هو من يحاكي اللعبة ويرسل الحالة للاعب الآخر.

## التحكم
**اللمس**: عصا يسار للحركة (اسحب للأسفل للانحناء) + زر 🚀 للطيران · عصا يمين للتصويب وإطلاق النار (اسحب للحافة للإطلاق) + زر ⟳ لإعادة التعبئة.

**الحاسوب**: `A/D` حركة · `W` أو `Space` طيران · `S` انحناء · الماوس تصويب وإطلاق · `R` إعادة تعبئة.

الفوز لأول من يحقق 5 تصفيات.
